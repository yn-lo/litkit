# 学术写作（Academic Writing）

写作方法论，

## 适用对象

- 研究论文（empirical / review）正文各章节
- 书籍章节（chapter / section）
- 摘要与开头的设计

## When to Use

- 撰写或修订论文正文、书籍章节，需要组织论证结构时
- 判断一段是否写得清晰、是否承重、该详该略时
- 规划引言钩子、设计标题与摘要时

## When NOT to Use

- 检索文献、管理引用库、合规验证 → 用 **litkit** 技能（随 init 生成；行文合规由 verify 自动判定）

## 正文结构（论证定位）

### 研究论文（IMRAD）

每一段先问「它答哪个问题」，结构跟随论证而非栏目：

- **引言**：漏斗式——领域背景 → 缺口 → 本研究的 question/hypothesis → 贡献。答"凭什么关心"
- **方法**：材料、对象、统计学细节，可复现为先。答"可信吗"
- **结果**：只陈述事实，结论留给讨论。答"得了什么"
- **讨论**：先答研究问题，再对比已有证据，最后限界与展望。答"对学科意味着什么"
- **结论/总结**：提炼 2-3 个可带走的主张，不重复整段结果

### 书籍章节

章节是自洽的论证单元，而非论文切片：开头立论并交代与全书的定位，正文展开，结尾回到跨章节推进。

## 判断启发式（写每段前自问）

1. **清晰度测试（Clarity Test）**：删掉这段，论证是否仍在？承重段值得反复打磨，支撑段一带而过
2. **读者旅程**：读者此刻能回答"我在哪 / 为何在这 / 该带走什么 / 下一步去哪"吗？任一不明即需修文
3. **学科语域**：医学/理工重精确与方法，社科重限界，人文重阐释——语域不对即换口吻
4. **So-What 层级**：引言"凭什么关心"、综述"缺什么"、方法"可信吗"、结果"得了什么"、讨论"对学科意味着什么"

## 摘要方法论

- **自足**：不依赖正文图表的编号；首次出现的缩写须定义
- **5 组件罩本**（可选）：背景/目的/方法/结果/意义，能覆盖一半即可，不必四平八稳——组装顺序可视目标期刊偏好调整
- **关键词选词**：5-7 个，补题目未覆盖的检索入口、不重复题目

## 修辞与开头

- **标题**：可读、可检索、不过度承诺；先做信息型裸题，再考虑修辞型
- **引言第一句**：避免空洞开场，用具体数字或反常现象直接立住读者注意力
- **反套路是判断，不是规则**：空泛措辞是否"刺眼"依赖语域判断，无法穷举成规则——这正是本技能存在的意义
