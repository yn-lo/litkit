# 学术写作 · 语言风格（Academic Style）

写作方法论，语言风格层，**全论文类型通用**（empirical / review / book 章节共用）。

与工具链的分工（避免越界）：

| 层 | 归属 | 示例 |
|---|---|---|
| 格式（章节构成/叙事顺序/每章写什么） | **manuscript-format** 技能（按类型取 references/）+ verify 规则 | 实证四段式八股、章节顺序 R1.9、标题 R1.2/R1.3、P 值 R2.1、引用 R5.x |
| 语言风格（判断性、无法规则化的部分） | **本技能** | 论证定位、叙事对齐、承重判断、修辞 |
| 工具流程（检索/入库/验证命令） | **litkit** 技能 | search / lib / verify |

本文只写"语言风格"这一层；凡是能写成确定性规则的，一律交给 verify，不在这里重复。

## When to Use

- 撰写或修订论文正文、书籍章节，需要组织论证结构、判断行文质量时
- 判断一段是否写得清晰、是否承重、该详该略时
- 规划引言钩子、设计标题与摘要时
- 成稿后需要按叙事结构做语言风格层面的自检时

## When NOT to Use

- 检索文献、管理引用库、格式合规验证 → 用 **litkit** 技能（行文合规由 `litkit verify` 自动判定）
- 规划章节构成、每章的叙事任务与顺序（八股骨架）→ **manuscript-format** 技能（按类型取 references/）
- 类型专属的章节清单、字数区间、引用阈值 → `manuscript-spec.yaml`（唯一事实源）
- 相当于把本文某一节硬塞成规则的诉求 → 停，问一句"这句判断真的能正则化吗"

## 正文结构（论证定位）

每一段先问「它答哪个问题」，结构跟随论证而非栏目：

- **引言**：漏斗式——领域背景 → 缺口 → 本研究的 question/hypothesis → 贡献。答"凭什么关心"
- **方法**：材料、对象、统计学细节，可复现为先。答"可信吗"
- **结果**：只陈述事实，结论留给讨论。答"得了什么"
- **讨论**：先答研究问题，再对比已有证据，最后限界与展望。答"对学科意味着什么"——**叙事顺序应与结果逐点对齐**：结果提了几个要点，讨论就按相同次序安排几段，一段对应一个结果（先报告再对照再阐释），头尾呼应研究目的。
- **结论/总结**：提炼 2-3 个可带走的主张，不重复整段结果

### 书籍章节

章节是自洽的论证单元，而非论文切片：开头立论并交代与全书的定位，正文展开，结尾回到跨章推进。

## 判断启发式（写每段前自问）

1. **清晰度测试（Clarity Test）**：删掉这段，论证是否仍在？承重段值得反复打磨，支撑段一带而过
2. **读者旅程**：读者此刻能回答"我在哪 / 为何在这 / 该带走什么 / 下一步去哪"吗？任一不明即需修文
3. **学科语域**：医学/理工重精确与方法，社科重限界，人文重阐释——语域不对即换口吻
4. **So-What 层级**：引言"凭什么关心"、综述"缺什么"、方法"可信吗"、结果"得了什么"、讨论"对学科意味着什么"

---

## 叙事对齐（结果 ↔ 讨论）

- 结果有多少个要点，讨论就安排多少段，**次序对应**
- 每段讨论 = 一句结论性回答 + 与已有证据的对照（支持/挑战/拓展）+ 差异成因 + 临床/实践意义
- 讨论开头要回扣引言提出的研究目的；讨论结尾诚实列局限性，不替结果"补解释"

这些是语义判断，verify 无法穷举为规则；成稿后逐条人工核对。

## 摘要方法论

- **自足**：不依赖正文图表的编号；首次出现的缩写须定义
- **5 组件罩本**（可选）：背景/目的/方法/结果/意义，能覆盖一半即可，不必四平八稳——组装顺序可视目标期刊偏好调整
- **关键词选词**：5-7 个，补题目未覆盖的检索入口、不重复题目

（摘要字数与是否含引用，由 verify R8.2 / R4.9 自动判定，这里不写阈值。）

---

## 修辞与开头

- **标题**：可读、可检索、不过度承诺；先做信息型裸题，再考虑修辞型
- **引言第一句**：避免空洞开场，用具体数字或反常现象直接立住读者注意力
- **反套路是判断，不是规则**：空泛措辞是否"刺眼"依赖语域判断，无法穷举成规则——这正是本技能存在的意义
