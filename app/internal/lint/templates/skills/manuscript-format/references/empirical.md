# 实证论著叙事格式（Empirical）

实证（原始研究）八股叙事，中英文同构。章节顺序：引言 → 资料与方法 → 结果 → 讨论 → 结论（zh）/ Introduction → Methods → Results → Discussion → Conclusion（en），以 `.litkit/empirical-<lang>/manuscript-spec.yaml` 的 `sections` 为唯一顺序源。

## 1 引言（Introduction）：是什么、为什么、做什么

漏斗式四层递进，末尾收束到一句可操作的研究目的：

1. **大背景**：疾病负担 / 健康问题的现实意义（引数据）
2. **已有共识**：前人在该领域已解决什么
3. **核心缺口（Gap）**：现存问题、争议或空白——全文创新根基，须有文献支撑，缺口要具体可论证
4. **研究目的**：清楚地说明本研究要验证什么 / 做什么

> 一句话检查：引言最后能否读出"本研究拟……"？读不出即缺目的层。

## 2 资料与方法（Methods）：怎么做、能否复现

按"一般资料 → 方法 → 观察指标 → 统计学方法"分层：

- **2.1 一般资料（Participants）**：病例来源、时间地点、纳入排除标准、样本量计算、基线特征
- **2.2 方法（Interventions/Design）**：对照组/干预组各自措施（观察组/对照组、干预臂/对照臂）；随机/盲法设计细节
- **2.3 观察指标（Outcomes）**：主、次要结局指标，测量工具及信效度
- **2.4 统计学方法（Statistical Analysis）**：软件及版本、所用检验、检验水准

验收：按此段可复现研究；指标清单即结果段回报清单。

## 3 结果（Results）：发现了什么——客观呈现

按"一般资料 → 主要结局 → 次要结局"回报，**与观察指标一一对应**：

- **3.1 一般资料（Baseline）**：三线表（Table 1）展示基线资料，组间均衡性检验（年龄、性别、病程、严重度等 P 均 >0.05 说明可比性，论证"两组起点一致"）
- **3.2 主要结局指标（Primary Outcome）**：核心结局（护理效果/满意度/量表评分），给出效应值与统计量
- **3.3 次要结局指标（Secondary Outcomes）**：按逻辑顺序列出，可与主要结果关联分析

三条纪律：
- **只陈述不解释**——机理留给讨论
- 图表已呈现的数字正文只做概括，不复述表格
- 不止写"有显著意义"，给出具体数值与 P 值（格式按 spec.yaml R2.1）

## 4 讨论（Discussion）：意味着什么——与结果逐点对齐

四段式，**次序与结果完全对应**：

1. **开头一句核心发现**：直接回应引言的研究目的（不复制结果细节）
2. **与前人研究对话**：一段对应一个结果，说明本研究支持/挑战/拓展了哪些结论，差异成因
3. **机制与临床意义**：可能的机制、临床价值与实践启示
4. **局限与展望**：客观列局限性，提出未来方向

对齐自检：结果有 N 个要点，讨论须 N 段按相同顺序回应（如结果先"满意度比较"，讨论就先回应满意度差异与原因）。

复述红线：结果的数值与统计值不要原样搬进讨论；文字概括趋势即可，仅在支撑"与前人对比 / 机制阐释"时引用必要数字——判据是"有没有解读、是否重复"，而非"有没有出现"。结论不得再搬结果细节。

## 5 结论（Conclusion）

提炼 2–3 个可带走的主张，不重复结果全文。
