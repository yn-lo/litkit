# 图表生成与排版规范（Figures & Tables）

> 适用对象：所有文稿类型（实证 / 质性 / 综述 / 书稿 / 标书）的图与表。目标期刊的《作者指南》优先于本文件；本文件只规定通用底线与默认做法。阈值（编号、数量）仍以 `litkit verify` 与 `manuscript-spec.yaml` 为准。

## 0 四条铁律

1. **先文后图表**：正文必须先引用（"如图 1 所示""见表 2"），图表才能出现；编号按正文首次出现顺序连续，图与表各自独立编号。
2. **自足**：读者只看图表与图注/表注就能读懂——样本量、单位、误差棒、缩写、统计方法、数据来源都在图注或表注里交代。
3. **不重复**：图不重复表中的数字，正文不复述图表里的每个数值；图表不承担论证，只承担查阅与呈现。
4. **可复现**：数据点、n、分母、统计检验与软件版本可追溯；不得只给"代表性图像"而无量化说明。

## 1 表格（Tables）

### 1.1 结构

- **三线表**：仅三条横线（表题下、表头下、表底），不加竖线；需要分组时用辅助横线，不用竖线或格子框。
- 表头写"量的名称/单位"或"量的符号/单位"（CY/T 170—2019），如 `年龄/岁`、`浓度/(mol·L⁻¹)`；单位不在每个单元格重复。
- 行列表头层级不超过 2 级；合并单元格仅用于表头分组，正文不放跨行的说明文字。
- 数值按小数点对齐；同一列有效位数一致（如均保留 1 位小数）；百分比注明分母。
- 空格、缺失与未检出须有定义：`—`（不适用）、`NA`（缺失）、`<LOD`（低于检出限），并在表注说明。
- 合计/总计行须标明是否含缺失值；组间比较的检验方法写进表注，不在表内堆星号。

### 1.2 表题与表注

- **中文刊**：表题在表上方（"表 1　×××"），表注在表下方（"注：……"）。
- **英文刊/APA 7**：编号（Table 1）与斜体题名在表上方；表注在下方，以 `Note.` 起首。
- 表注顺序（APA 7）：**一般注**（缩写、符号、整体说明）→ **特殊注**（上标 a、b、c 对应具体单元格）→ **概率注**（*P* 值，若适用）。
- 缩写首次出现必须定义；引用他人数据须注明来源与许可。

### 1.3 内容

- 表中不写完整句子；描述性统计与 n 齐全。
- 与正文、图重复的数字删掉一处（通常保留图表）。
- 质性论文的参与者特征表只放描述统计；目的性配额的分布须注明"非自然流行率"。

## 2 插图（Figures）

### 2.1 图形选型

- 比较类别用柱状图（纵轴必须从 0 起，不得截断）；时间/连续变量用折线或散点；分布用箱线图或小提琴图并说明须与异常值定义。
- 折线只连接有连续意义的点；无插值意义的分类点不连线。
- 避免双纵轴；确需双轴时在注释中明确两侧变量与刻度，并说明可能误导的方向。
- 箱线图必须说明是 min–max 还是 1.5×IQR，点是否显示个体值。

### 2.2 配色（关键）

- **分类色默认用 Okabe-Ito / Wong 8 色**（Nature 系列推荐，色盲友好）：黑 `#000000`、橙 `#E69F00`、天蓝 `#56B4E9`、蓝绿 `#009E73`、黄 `#F0E442`、蓝 `#0072B2`、朱红 `#D55E00`、紫红 `#CC79A7`。
- 连续/顺序数据用 **viridis / magma / plasma** 等感知均匀色阶，不用彩虹色（jet）。
- **不得只靠颜色区分**：叠加形状、线型、纹理或直接标注；转灰度后仍须可读。
- 前景与背景对比度足够；浅色网格线、去背景色块；同一图内语义色一致（如"患者"始终同色）。
- 质性论文禁用红绿对立表达"好/坏""进步/退步"。

### 2.3 字号、线宽与尺寸

- 字体用无衬线（Arial / Helvetica），**成品尺寸下 5–7 pt**（正文图建议 7 pt），全图统一；panel 标签 A/B/C 左上角、字号一致。
- 线宽 ≥0.25–0.5 pt；坐标轴线与数据线粗细区分；刻度朝内或朝外按目标刊统一。
- 尺寸按成品尺寸设计：单栏约 85–90 mm，双栏约 170–183 mm（Nature 系 89/183 mm，其他刊以指南为准）；文字与线宽按最终尺寸设置，不靠缩放。

### 2.4 分辨率与格式

- 常见底线：照片/灰度图 ≥300 dpi；线条图 ≥600 dpi；组合图 ≥600 dpi，部分刊要求 1200 dpi（线稿）。
- 优先矢量格式（PDF / EPS / SVG）；位图用 TIFF/PNG，不用 JPEG 存线条图。
- 不缩放、不插值放大；导出后在 100% 尺寸下检查文字是否可读。

### 2.5 坐标轴、单位与统计标注

- 单位用 SI；轴标签写"变量（单位）"；不用 ppm/ppb，改用 SI 分数（如 µmol/mol）。
- 纵轴刻度与量程不夸大差异；柱图从 0 起。
- **误差棒必须定义**：SD、SEM 还是 95% CI，写进图注；不写"误差棒表示离散程度"。
- **n 必须给精确值与定义**：受试者数、事件数还是技术重复，如 `n = 12 名患者`；不接受 `n = 5–12`。
- 检验方法、统计量与 *P* 值写进图注；用星号时须在图注定义（常见 *P*<0.05、**P*<0.01、***P*<0.001，以目标刊为准）；能给精确 *P* 值就不只给星号。
- 质性研究不把主题/事件计数画成频次柱图或百分比趋势图；概念关系图须标注"分析性框架，不表示因果强度或时间顺序"。

### 2.6 图注（Legend）

- 图注置于图下方（APA 7 用 `Note.`；中文刊图题在图下，图元注可在图内图号图题上方、整图注在下方——CY/T 171—2019）。
- 结构：**一句结论式图题** → 方法与样本（谁、多少、如何处理）→ 统计与误差棒定义 → 缩写与符号 → 来源/许可。
- 图注自足：不要求读者回正文找 n 或误差棒含义。
- 图内元素标注（图元注）用数字或符号指引，注文与注码之间用一字线或下圆点，各条注用分号、末条用句号（CY/T 171—2019）。

### 2.7 图像完整性

- 不做选择性增强、局部擦除或拼接；凝胶/显微图保留原始全图与裁剪说明；调整亮度/对比度须全图一致并声明。
- 复用的已发表图须获许可并标注来源。

## 3 图表通用排版

- 编号：图 1、表 1 连续；补充材料用 Figure S1 / Table S1（或"附图 1/附表 1"），与正文编号不混。
- 图表标题不超过 1–2 行；题名给结论或内容，不写"×××图"式重复。
- 图表出现在首次引用之后；跨页表格重复表头。
- 中文刊数字与单位间留半角空格；百分号、摄氏度紧跟数字（`37 ℃` 可按刊规）。
- 表注、图注中的缩写与正文首现定义一致；中英文术语映射统一。

---

## 4 质性论文的追加要求

- 参与者特征表做间接识别防护：罕见诊断不与精确年龄、具体照护关系、精确机构/病区组合；年龄用区间、罕见诊断合并。
- 引语不放进图里；主题表（表 4）表注写明"例证为说明性举例，不代表频次"。
- 关系图/概念图只表达分析框架，图注写明"不表示因果强度、时间顺序或预测能力"。

---

## 5 投稿前图表自检（10 条）

1. 每个图表都在正文首次引用之后出现，编号连续、无跳号。
2. 三线表、无竖线；表头含"量/单位"；小数位对齐且一致。
3. 表题在上、表注在下；一般注→特殊注→概率注顺序正确；缩写已定义。
4. 分类配色为 Okabe-Ito/Wong；连续数据用 viridis 类色阶；灰度下仍可区分。
5. 成品尺寸下字号 5–7 pt、线宽一致；panel 标签统一。
6. 分辨率达标（照片 ≥300 dpi、线条 ≥600 dpi）或使用矢量格式。
7. 柱图纵轴从 0 起；无双纵轴或已说明理由；折线不连无意义插值。
8. 误差棒类型、精确 n 及其定义、检验方法与 *P* 值均在图注中交代。
9. 图注自足；中文刊图注位置符合 CY/T 171；英文刊用 Note. 格式。
10. 图不重复表中数字；正文不复述图表每个数值；图表与正文、摘要的数字一致。

## 参考标准

- CY/T 170—2019《学术出版规范 表格》：表头"量的名称或符号/单位符号"
- CY/T 171—2019《学术出版规范 插图》：图元注与整图注的位置与注码格式
- APA 7th：表/图编号与斜体题名在上，Note. 在下；一般注、特殊注、概率注顺序
- Wong B. Points of view: Color blindness. *Nat Methods* 2011（Okabe-Ito 调色板，Nature 系推荐）
- Nature / Science 系作者指南：图注须含精确 n、误差棒定义、统计检验与 *P* 值定义
