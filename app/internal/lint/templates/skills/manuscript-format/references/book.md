# 书稿叙事格式（Book）

中文书籍/医学专著书稿。书稿按"章"成册，`sections` 清单不启用（R1.5/R1.9 对 book 跳过）。此处给"章"与"节"的叙事单位规范。

## 章节为自洽的论证单元

- **章首**：立论 + 交代本章在全书中的定位/与前章衔接
- **正文**：按"篇 → 章 → 节 → 目"的中文编号体系组织（第一篇/第一章/第一节/一、/（一）/1.），逐级递进
- **章末**：小结并指向下一章推进

## 单章叙事自检

1. 本章能否独立成读？开头是否说明"这一章讲什么"
2. 节与节是否有逻辑递进（概念 → 机制 → 应用），而非并列堆料
3. 结尾是否回扣章首立论并留出跨章接口

## 示例骨架

```markdown
# 第三章 腹部创伤的病理生理       ← 章

## 第一节 腹部创伤的力学机制      ← 节
### 一、钝性损伤               ← 目
### 二、锐性损伤

## 第二节 临床评估
```
