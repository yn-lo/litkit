# 人工审查清单 — 自动化无法覆盖的 M 类规则终审

> 由 litkit 生成。`litkit verify` 输出 0 错误后，逐项人工复核下列条目。
> 章节结构按 specs/manuscript-spec.yaml 的 paper_type 调整。

## 一、结构完整性（M）

- [ ] 引言是否包含研究背景、目的与意义，并客观评介前人研究、指出研究空白
- [ ] 资料与方法是否完整描述研究设计、对象与纳入排除标准、工具及信效度、统计方法
- [ ] 结果是否按观察指标顺序报告，不作主观解释
- [ ] 讨论是否结合文献解释结果、指出局限性
- [ ] 结论是否提炼核心发现（非各章小结重复）
- [ ] 涉及人体/动物研究是否说明伦理审查与知情同意

## 二、语言与行文（M）

- [ ] 全文术语是否统一；专业术语首次出现是否添加缩写定义
- [ ] 是否杜绝口语化表述；行文是否谦逊、无未论证词汇
- [ ] 同级并列内容是否合并在同一段落（分号连接）
- [ ] 括号内是否无解释性长句

## 三、数据与统计（M）

- [ ] 同一指标在摘要、正文、表格中的数值是否完全一致
- [ ] 均值与标准差小数位是否一致；效应量与置信区间格式是否规范
- [ ] 百分比/率的小数位是否按规则（1 位小数，必要时 2 位）

## 四、文献引用（M）

- [ ] 所有 [@xxx] 是否指向真实存在的文献（禁止编造）
- [ ] 引用篇数是否在 manuscript-spec.yaml 的 citation.count 区间
- [ ] 引用密度是否合理（单行不超过 3 篇）

## 五、AI 痕迹（M）

- [ ] 标题是否无冒号；是否无自我夸大式表述；是否无回引
- [ ] 整体行文风格是否自然、专业，无模板腔

## 六、用户意见（M）

- [ ] 文稿中所有【】标记是否已针对性处理完毕
